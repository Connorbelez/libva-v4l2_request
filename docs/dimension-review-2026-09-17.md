## Reproduced findings and corrections

1. **Picture admission bypassed the shared backend contract.** The new picture
   check only used the fixed AVD 64..4096 constants. A decoder reporting a maximum
   of 128 still accepted a 129-pixel picture inside a valid context; stepwise and
   discrete-pair restrictions were likewise ignored. Three new public-VA
   regressions failed on the contributor head. Picture admission now uses the
   selected decoder's shared contract, including narrower bounds and generic
   backend constraints. An unchanged context-size pair needs no extra ioctl.
2. **Encoded dimensions could disagree with the admitted VA dimensions.** The
   existing uncompressed-header parser skipped explicit frame sizes. A header
   encoding an 8-pixel axis with VA dimensions of 64 was accepted, bypassing the
   intent of the new boundary. A new parser/submission regression failed before
   correction. Key, intra-only and explicit-size inter frames now require exact
   coded-size agreement with VA parameters before output append or submission.
3. **Configuration teardown could free the object during dimension I/O.**
   `vaQuerySurfaceAttributes` retained a borrowed config pointer while querying
   the device. A deterministic DestroyConfig interleaving inside the enumeration
   ioctl produced an ASan heap-use-after-free in `surface.c`. The query now copies
   the immutable config under the handle-table mutex, releases the mutex before
   device I/O, and uses its owned snapshot. The regression then passes, and a
   subsequent query correctly reports the destroyed config as invalid.

The focused suite has 23 cases: 18 dimension fixtures and five VP9 cases.
It includes both AVD and generic narrower/stepwise/discrete contracts, fallback

checks both axes for profiles 0/2 across all three explicit-size header forms.
Reference-sized inter frames retain their existing reference-validation path;
